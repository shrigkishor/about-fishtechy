# Fishtechy — web v2

A rebuild of the Fishtechy public web surface: marketing pages and storefront,
in a scroll-led editorial style.

## Running it

```bash
pnpm install
cp .env.example .env.local   # then point NEXT_PUBLIC_HERO_REEL_URL at the reel
pnpm dev                     # http://localhost:3100
```

`pnpm build` for a production build, `pnpm lint` / `npx tsc --noEmit` to check.

## Environment

| variable | required | notes |
| --- | --- | --- |
| `NEXT_PUBLIC_HERO_REEL_URL` | no | The homepage hero reel (~84MB, served from a CDN rather than bundled). |

`NEXT_PUBLIC_` means Next inlines it at **build** time, so it has to be set
wherever the build runs, not only where the site is served. Leaving it unset is
supported: the hero renders without footage and keeps its own ground — verified
by building with it absent.

## Stack

Next.js 16 (App Router) · React 19 · Tailwind v4 · GSAP + ScrollTrigger ·
Lenis · Three.js (unused, see below).

## How the page is put together

- **Smooth scroll** — Lenis, driven off GSAP's ticker so both run on one clock.
  Two clocks judder pinned sections against parallax layers beside them.
- **Stacked sections** — each is a tall sizer holding a one-screen sticky frame.
  The gap between them is dwell: how long a section stays readable before the
  next climbs over it. A section must fit one screen, or its lower half becomes
  unreachable once pinned.
- **Horizontal rails** — the product lineup and the app showcase are driven by
  vertical scroll: the section holds while the row walks left, then releases.
  Mouse drag works on top of it. The wheel is deliberately left alone.
- **Reveals** — triggered by `IntersectionObserver`, not ScrollTrigger, because
  ScrollTrigger's recorded document position stops matching reality inside a
  sticky container. Each carries a timeout so content can never stay invisible.
- **Revealed footer** — held behind the page and uncovered as the content
  scrolls off it. Falls back to normal flow when it is taller than the viewport,
  since a fixed element cannot be scrolled to.

## Design tokens

The palette is sampled from the logo mark rather than guessed:

| token | value | notes |
| --- | --- | --- |
| `flare` | `#ea8e50` | lightest stop of the mark's gradient |
| `flare-deep` | `#c93727` | darkest stop; used on light grounds |
| `brand-blue` | `#0f4d86` | the fin and eye; links, secondary buttons |
| `brand-blue-lit` | `#187edb` | same hue lifted for dark grounds |

The logo blue is 2.29:1 on the ink ground, below AA, which is why the lifted
variant exists.

## Product photography

`product.webp` shots are opaque studio images on pure white. `product-cutout.webp`
beside each one is the same shot with the paper keyed to alpha, generated by
flood-filling the border-connected neutral region and punching the balls'
enclosed keyring holes. The cutouts are what the cards use.

  current site.
